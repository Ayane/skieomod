INSTALL AND PLAY

Your next mountain.
A few clicks away.

Close Ski-E-O!, install it through Steam and launch it once. Download the installer for your system; it checks Python and pipx, installs what is missing, then runs the mod setup.

Windows

Download the Windows installer ↓

Double-click the downloaded .cmd. Windows may ask you to confirm running it. Keep its terminal open until it reports completion. Python 3.10+ is reused when available; otherwise it installs the signed, checksum-verified Python 3.13.17 x64 package for your user.

Requires x64 Windows and the Steam Windows game or demo. The game does not support Windows on ARM.

Linux / Proton

Download the Linux installer (.sh) ↓

In the downloaded file’s properties, allow executing it as a program, then choose Run in Terminal. If your file manager opens it as text, open a terminal in the download folder and run bash Install-SkiEO-Linux.sh. If Python/venv is missing, your distribution may ask for your sudo password. The tools and mod install for your normal user.

Launch the game once through Steam to create its Proton prefix. Debian/Ubuntu, Fedora, Arch and openSUSE package managers are recognised. Other distributions need Python 3.10+ and venv/ensurepip installed first.

After installation

Start the game through Steam and select New Game → Custom Map. Choose a map and press Play; the map downloads separately. Running the installer again updates the tools and loader. Existing maps and saves are preserved.

If both the full game and demo are installed, choose the one you intend to use when setup asks. If setup cannot find Steam, follow its folder-selection prompt. The terminal stays open with the result; read its error if installation stops.

macOS

The native macOS game cannot load the current Windows DLL-based mod. There is no Mac mod installer in this release. The authoring tools can be installed separately for map creation.

Read the scripts

The installers use normal HTTPS certificate validation. The Python fallback is downloaded from python.org and checked before execution. pipx keeps the tools separate from system Python.
